# Data sources and how to add real companies

## What is bundled

`data/sample/synthetic_financials.csv` holds **four fictional companies** (every name ends in "(Synthetic)").
They were generated by `scripts/generate_synthetic_data.py` from simple business drivers, so the accounting
identities hold exactly. They exist to test the software and demonstrate edge cases:

| Synthetic company | Sector | What it demonstrates |
|---|---|---|
| Alpha Manufacturing | Industrial Manufacturing | Healthy, listed (has market cap) → original Altman Z |
| Kestrel Infrastructure | Infrastructure | Steady deterioration: rising debt, falling coverage, current ratio < 1 |
| Lotus Consumer Goods | Consumer Goods | Becomes debt-free → debt-service ratios "not applicable" |
| Orbit Aviation Services | Aviation Services | Losses, negative EBITDA and **negative equity** → "not meaningful" ratios |

**No synthetic result describes a real company.** The dashboard, PDF and Excel outputs all carry a SYNTHETIC
banner while this file is in use.

## Why real data is not bundled

The analysis needs line items such as current assets, inventory, cash, short- and long-term borrowings,
retained earnings and capital expenditure. Free summary websites often merge these lines, so they have to
be read from the **annual report** (or the XBRL filing). Copying them needs care and must be traceable, so
this is left as a deliberate, documented step rather than done by an automated scraper.

## Adding real companies (about 30-45 minutes per company for 3 years)

1. **Choose 3+ listed, non-financial Indian companies**, ideally from different sectors (for example one
   manufacturer, one consumer company, one infrastructure or services company). Do not use banks, NBFCs or
   insurers: their balance sheets work differently.
2. **Download the annual reports** for 3-5 years from the company's investor-relations page or from the
   NSE/BSE filings page for the company.
3. **Pick one basis and stick to it.** Use the **consolidated** statements for every year of a company (or
   standalone for every year, but never a mix). Use one unit (e.g. INR crore) for all years.
4. Copy `data/raw/company_financials_TEMPLATE.csv` to `data/raw/company_financials.csv` and fill one row per
   company per year. Where to find each item in an Ind AS annual report:

| Column | Where to find it (Ind AS statements) |
|---|---|
| current_assets | Balance sheet → "Total current assets" |
| current_liabilities | Balance sheet → "Total current liabilities" |
| cash_and_equivalents | Balance sheet → "Cash and cash equivalents" (do not add other bank balances unless you note it) |
| inventory | Balance sheet → "Inventories" |
| total_assets | Balance sheet → "Total assets" |
| total_liabilities | Balance sheet → "Total liabilities" (or non-current + current liabilities) |
| total_equity | Balance sheet → "Total equity" (include non-controlling interest consistently if consolidated) |
| short_term_borrowings | Current liabilities → financial liabilities → "Borrowings" + current lease liabilities (INCLUDED under Ind AS 116). |
| long_term_borrowings | Non-current liabilities → financial liabilities → "Borrowings" + non-current lease liabilities; lease liabilities are INCLUDED (Ind AS 116: finance costs already contain lease interest and EBITDA already excludes lease rent). |
| retained_earnings | Notes to "Other equity" → "Retained earnings" |
| revenue | P&L → "Revenue from operations" |
| ebitda | Not reported as such: compute **EBIT + depreciation & amortisation**, and keep the same definition every year |
| depreciation_amortisation | P&L → "Depreciation and amortisation expense" |
| ebit | Compute as **profit before tax + finance costs** (state in sources.csv whether exceptional items are included) |
| interest_expense | P&L → "Finance costs" |
| profit_before_tax | P&L → "Profit before tax" |
| net_profit | P&L → "Profit for the year" |
| operating_cash_flow | Cash flow statement → "Net cash generated from operating activities" |
| capital_expenditure | Cash flow statement → purchase of property, plant & equipment (and intangibles), entered as a **positive** number |
| lease_principal_payments | Optional, positive outflow: consolidated cash flow statement ? financing activities ? "Repayment/payment of principal portion of lease liabilities" (or separately printed lease repayment with interest shown separately). Cite file/page and convert to INR crore. If only a combined principal+interest line is printed, record it as printed and say so; preserve any net-of-incentives wording. Used in FCF = OCF ? capex ? provided lease payments; OCF/debt is unchanged. If blank/absent, retain before-lease FCF and disclose the basis note. |
| market_capitalisation | Optional; use only market capitalisation printed in the annual report as at 31 March, converted to INR crore and cited by PDF file/page. Do not calculate from share prices; leave empty if not printed (needed only for the original Altman Z). |

5. A printed dash "-" means nil: enter **0** and record "printed as '-' (nil)" with the PDF file/page. **Leave a cell empty** only if the line item does not appear. Never type 0 for "unknown": the software
   treats missing values explicitly and reports which ratios could not be computed.
6. Set `data_type` to `REAL`, and add one line per company and year range to `data/sources.csv`
   (document name, URL, page, consolidated/standalone, units, date accessed, and any adjustment you made).
7. Run `setup_project.bat` (or `python scripts/prepare_data.py`). The validation report lists any problem,
   for example if assets do not equal liabilities plus equity. Fix those, then start the dashboard.

As soon as `data/raw/company_financials.csv` exists, the whole application uses it instead of the synthetic set.

## Licensing

Annual reports of listed companies are public disclosures. Cite the source document for every figure. The
`.gitignore` excludes `data/raw/company_financials.csv` by default; remove that line only once every figure
is sourced in `data/sources.csv`.
